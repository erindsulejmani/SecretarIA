# GitHub: Miniera di Informazioni Tecniche

GitHub è una fonte pratica di [[OSINT per l'Intelligenza Artificiale|OSINT]] tecnico, particolarmente ricca per analizzare progetti software e di IA. Quattro aspetti da osservare:

1. **Commit history**: analizzare i commit rivela priorità di sviluppo, bug fix, nuove feature. Frequenza e tipo di commit indicano la maturità del progetto.
2. **Issues e pull request**: discussioni tecniche, problemi aperti, feature request. Indicano limitazioni attuali e direzioni future.
3. **Contributors e community**: chi contribuisce? Aziende, università, individui? Dimensione e attività della community indicano adozione e supporto.
4. **Dependencies**: quali librerie usa il progetto? I cambiamenti nelle dipendenze rivelano shift tecnologici e problemi di compatibilità.

GitHub è anche il luogo dove si trovano i [[Changelog di Modelli e Librerie]], un'altra fonte pratica utile a monitorare l'evoluzione tecnica nel tempo.
