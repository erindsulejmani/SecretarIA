# Changelog di Modelli e Librerie

I changelog, ovvero la lista dei cambiamenti apportati con il rilascio di una nuova versione, sono spesso sottovalutati ma contengono informazioni preziose su evoluzione, priorità e problemi risolti di un progetto software o di IA. Sono una fonte pratica di [[OSINT per l'Intelligenza Artificiale|OSINT]], reperibile tipicamente su [[GitHub come Fonte di Informazioni Tecniche|GitHub]].

**Cosa cercare nei changelog**:
- Breaking changes (indicano shift architetturali)
- Performance improvements (ottimizzazioni)
- Bug fixes (problemi noti e risolti)
- Deprecations (feature in uscita)
- New features (direzioni future)
- Security patches (vulnerabilità)

**Esempi di fonti**: PyTorch release notes, TensorFlow changelog, Hugging Face transformers, OpenAI API updates, NVIDIA CUDA toolkit, cloud provider ML services.

Monitorare i changelog è un modo concreto per valutare la [[Currency Valutare l'Attualità|Currency]] (attualità) di una tecnologia o di una fonte tecnica.
