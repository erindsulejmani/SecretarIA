# Machine Learning

Il Machine Learning (ML) è il sottoinsieme dell'[[Intelligenza Artificiale]] che apprende dai dati. In sostanza, non programma regole rigide ma trova pattern nei dati.

Più precisamente, il ML è un sottocampo dell'IA che si concentra sullo sviluppo di algoritmi che permettono ai computer di apprendere dai dati senza essere esplicitamente programmati per ogni singolo compito.

Nella [[Gerarchia IA ML DL GenAI]] il ML è descritto come "una tecnica di AI" per l'apprendimento automatico dai dati, ed è il livello che precede il [[Deep Learning]] (un tipo avanzato di ML basato su reti neurali profonde).

Il funzionamento del ML segue tre fasi (vedi [[Come Funziona il Machine Learning]]): dati di input, riconoscimento di pattern, risultato. Il mattone fondamentale su cui si basa tutto il processo sono i [[Dati di Training]], la cui qualità e quantità sono cruciali per le prestazioni del modello.

Il ML si concretizza attraverso [[Algoritmi e Modelli]]: gli algoritmi sono le procedure matematiche che permettono di apprendere dai dati (il "come"), mentre i modelli sono il prodotto di tale apprendimento (l'output addestrato, usato per fare previsioni).

Esistono tre tipi principali di Machine Learning: [[Apprendimento Supervisionato]], [[Apprendimento Non Supervisionato]] e [[Apprendimento per Rinforzo]].

Esempi pratici di ML moderno nel mondo aziendale citati nel deck: modelli di scoring clienti (marketing), previsione di interruzione nei servizi.
