# Cos'è un Prompt

Un prompt è il testo d'ingresso che si fornisce ad un modello AI come ChatGPT, Claude, Gemini o Midjourney. È come un comando naturale, una richiesta, un contesto o una descrizione, a seconda dell'uso.

Principio chiave delle slide: "Il prompt è alla base della qualità del risultato, non è magia: è progettazione linguistica."

Un esempio pratico mostra la differenza tra un prompt generico e uno migliorato:
- **Prompt Base (Generico)**: "Spiega cos'è l'intelligenza artificiale." — Funziona, ma è troppo aperto e rischia un output variabile.
- **Prompt Migliorato**: "Agisci come un docente di informatica. Spiega cos'è l'intelligenza artificiale a un gruppo di studenti delle scuole superiori. Usa un tono semplice e quotidiano. Includi 3 esempi pratici." — Più specifico, la risposta è più mirata, leggibile e utile.

Questo esempio introduce concretamente l'idea alla base della [[Formula Base del Prompt]] (ruolo, obiettivo, dettagli, contesto, formato atteso), che il deck presenta subito dopo come struttura generale per scrivere prompt efficaci.
