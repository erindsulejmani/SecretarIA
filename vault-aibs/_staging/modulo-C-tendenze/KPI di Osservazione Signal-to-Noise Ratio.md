# KPI di Osservazione: Signal-to-Noise Ratio

Il signal-to-noise ratio è il rapporto tra segnali veri e distorti; garantisce un tasso di maturità accettabile del sistema di osservazione.

**Qualità vs Quantità**: non tutti i segnali hanno uguale valore. Il rapporto signal-to-noise misura l'efficacia nel filtrare informazioni rilevanti dal [[Pattern vs Rumore|rumore]] di fondo.

- **Formula**: (Segnali actionable / Totale segnali raccolti) × 100
- **Target**: >30% per un sistema maturo

Si migliora attraverso: filtri più precisi, machine learning per la prioritizzazione, feedback loop continuo.
