# Modello AI

Il modello AI è l'output dell'algoritmo di machine learning (nella IA moderna, basati su [[Rete Neurale|reti neurali]]). La scelta dell'algoritmo di machine learning più adatto per affrontare un determinato task dipende da tanti fattori.

Per creare un modello bisogna dare "in pasto" all'algoritmo di machine learning la rappresentazione vettoriale di un "train set", ovvero l'elaborazione dei dati di origine.

Collegamenti: [[Rete Neurale]], [[Transformer]], [[Processo di Sviluppo dell'IA Moderna]]
