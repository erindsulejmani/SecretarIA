# Prompt Engineering

Il Prompt Engineering è una competenza chiave per chi lavora con l'AI generativa, soprattutto in ambiti creativi, comunicativi e analitici. Riassume le conoscenze e la capacità di sapere scrivere istruzioni efficaci per l'IA.

Principio guida citato nelle slide: "un prompt ben scritto è la base per ottenere un output di qualità."

Obiettivi dichiarati del modulo: comprendere cos'è un [[Cos'è un Prompt]], perché è importante e come costruirne uno efficace per diversi obiettivi (testo, codice, immagini, analisi).

Il deck presenta diversi strumenti pratici per il prompt engineering:
- [[Formula Base del Prompt]] (Ruolo, Obiettivo, Dettagli, Contesto, Formato atteso)
- [[Errori Comuni nei Prompt]] da evitare
- [[Migliori Pratiche di Scrittura dei Prompt]]
- Formule avanzate strutturate: [[Formula Chain of Thought]], [[Formula IDEA]], [[Formula REACT]], [[Formula DEFINE]], [[Formula STAR]], [[Formula TOME]] e [[Formula AGILE User Story]]

Il Prompt Engineering è anche il punto di partenza per capire il processo tecnico che porta dal testo dell'utente alla risposta del modello, descritto in [[Dal Prompt all'Output]] e [[Processo di un Assistente IA Conversazionale]].
