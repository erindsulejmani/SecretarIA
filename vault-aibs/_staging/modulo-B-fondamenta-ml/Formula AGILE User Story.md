# Formula AGILE User Story

Indicata come "la mia formula preferita" dal docente, la formula AGILE user story adatta al prompt engineering la struttura tipica delle user story del metodo Agile, usata in ambito sviluppo software.

Struttura:

> **As a** [social media user]
> **I want** [the ability to upload photos and tag people]
> **so that** [I can share significant events with my friends]

Le slide mostrano anche un template più esteso, che include Title, Priority, Estimate, la Story (As a <stakeholder> / I want <functionality> / so that <benefit>) e gli Acceptance criteria in formato Given/When/Then (<context> / <action> / <outcomes>) — un formato tipico anche della scrittura di requisiti in ambito Agile/Scrum.

Nota del docente: "È indubbiamente un modello base adattato. Dipende dalla domanda e dal contesto: se devo apprendere faccio domanda diretta, cerco di essere sempre amichevole."

Questa formula si distingue dalle altre (vedi [[Formula IDEA]], [[Formula TOME]], [[Formula STAR]]) per la sua origine specifica nel mondo dello sviluppo software Agile, risultando particolarmente utile per definire requisiti, funzionalità o specifiche di prodotto tramite prompt.
