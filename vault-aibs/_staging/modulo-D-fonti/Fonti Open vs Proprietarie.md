# Fonti Open vs Proprietarie

Le fonti si distinguono anche per modalità di accesso.

**Fonti open**: accessibili pubblicamente senza restrizioni significative. Includono paper open access, dataset pubblici, modelli open source, documentazione pubblica.
- Vantaggi: verificabilità, riproducibilità, costo zero, supporto della community.
- Limiti: qualità variabile, meno supporto formale, possibili gap di documentazione.

**Fonti proprietarie**: richiedono licenze, abbonamenti o accessi speciali. Includono report di analisti, database commerciali, API a pagamento, documentazione riservata.
- Vantaggi: qualità curata, supporto professionale, dati esclusivi, aggiornamenti garantiti.
- Limiti: costi elevati, verificabilità limitata, vendor lock-in.

**Come bilanciare le due tipologie** (in tre passi):
1. Inizia con l'open: usa fonti aperte per costruire una base di conoscenza solida e verificabile.
2. Integra il proprietario: aggiungi fonti proprietarie per insight esclusivi e dati di mercato specifici.
3. Valida incrociando: confronta informazioni da entrambe le tipologie per massimizzare l'affidabilità (principio alla base della [[Triangolazione delle Fonti]]).

Questa distinzione è una delle due dimensioni critiche usate nella [[Matrice di Selezione delle Fonti]] per orientare la scelta della fonte più adatta al contesto e agli obiettivi della ricerca.
